# Token Monitor (v0.5.1 Beta)

The `agy-token-monitor` plugin provides a real-time, pure read-only Auxiliary Pane (`Token Monitor`) backed by the `monitor_pane` sidecar.

## What Token Monitor Tracks

- **Unified Visual Design, Performance & Project Insights (v0.5.1)**: Uses a consistent type, spacing, and WCAG AA light/dark color token system with calmer status semantics (neutral grey for idle, accent for live activity, amber reserved for warnings), single-color inline SVG icons replacing emoji, borderless inset surfaces, dimmed cost hero decimals, and per-model color dots matching the Pixel Office palette. Includes fast big-Swarm refresh, hidden-tab poll pausing, on-demand idle timers, Windows-safe atomic saves, full keyboard accessibility, a per-period **By Project (`按项目分布`)** 5-column breakdown card (Top-8 folding) in Tab 2, and a persistent in-memory search/model/active-only filter bar for the Tab 2 session list.

- **Interactive Pixel Office (`像素工位`)**: Zero-dependency Canvas 2D workstation card (`pixel_office.js`) at the top of Tab 1 featuring a **`32×32` Main Cat** and **`24×24` Subagent/Swarm Cats** across **9 model-specific personas** (`Gemini 4 Carbon`, `Gemini 4 Neon`, `Gemini 4 Argon`, `Gemini 4 Hydrogen`, `Gemini 3.1 Pro`, `Gemini 3.8 Flash`, `Claude Opus 5.5`, `Claude Sonnet 5.5`, `GPT-OSS 120B`) plus an **`Auto` fallback cat** (`160` lazily baked sprites). Uses **round-scoped subagent filtering** (`selectRoundChildren`) so the studio shows only active/current-round subagents while working — or the last completed round plus alive/standing workers when idle — hiding older retired subagents from prior rounds while keeping full worker history in the breakdown table below. Enforces a **`1 Main + Max 8 Subagents`** workstation cap per displayed round with a clickable **`+N`** archive pill that expands & scrolls to the subagents/models card, drives live typing cadence from `tok/s` (`GENERATING`), floating tool bubbles (`RUNNING_TOOLS` via `activeToolLabel`), `IDLE`, and `ENDED` sleeping cats with `zZ` (pausing at `0 fps` when hidden, off-tab, or collapsed), offers a streamlined click-to-inspect `48×48` portrait badge showing the canonical model pill (without cat nicknames or trait descriptions), the raw model slug alongside the status line (e.g. `● 待命中   gemini-flash-worker-agy`), live stats (`Ctx`, `tok/s`, `Out`, Cost), & direct conversation navigation (`监控详情` / `打开会话` / `返回当前对话`), and persists a **Collapse/Expand (`收起` / `展开`)** header toggle (`pixelOfficeCollapsed`).
- **Live Speed & Status (`tok/s`)**: Current generation state (`GENERATING` 100ms stopwatch, `RUNNING_TOOLS` progress, or `IDLE`), active model timeline, latest `tok/s`, weighted average, peak speed, and recent 20-step sparkline — computed using SQLite `completedAtMs` timestamps (avoiding streaming timestamp spikes) and scoped to the active model.
- **Context Usage Monitor (`409.6k / 512k`) & One-Click `/compact`**: Active conversation context (`input_tokens + cache_read_tokens`) compared against configurable defaults: **`409.6k` (`409,600`, 80% `WARNING`) alert threshold** and **`512k` (`512,000`) max window** (`471.04k` / 92% `CRITICAL`), automatically migrating untouched legacy defaults via `PREFS_SCHEMA_VERSION = 4` while preserving custom user limits. Includes a one-click **`/compact`** helper button in the context header that copies `/compact` to the clipboard (and focuses a non-bound session chat if inspected) so the user can compress context immediately.
- **Bilingual UI (`EN / 中`) & Selectable Token Units**: Header `EN / 中` toggle next to Settings switches the full interface immediately between English and Simplified Chinese; 4 selectable token display units (`K/M/B` auto-scale, `万/亿`, exact integer `1,234,567`, and fixed `M`) are available in both the Analytics header and Settings drawer, with zero-layout-shift slot-roll transitions on live metric updates (per-digit rolling for matching lengths, whole-value swaps on unit or length changes, per-card DOM memoization, and `prefers-reduced-motion` support).
- **Session Total Tokens, Equivalent Cost, Per-Model Cache Hit Rate & Sortable Breakdowns**: Tab 1's Equivalent Cost card displays session `Total Tokens` (`总 Token 消耗`, computed from uncached input + cache read + output tokens, scoped dynamically to `With Subagents` / `Main Only` and formatted with the selected `tokenUnit`) alongside step count, and Tab 2 conversation rows also display per-session `Total` tokens. Both Tab 1 (Current Session) and Tab 2 (Usage Statistics) model distribution tables include a dedicated **Per-Model Cache Hit Rate (`Hit %` / `命中率`)** column right after `Cache` (`缓存`) — computed as `cacheRead / (uncachedInput + cacheRead)` with tiered visual coloring and `Cache Read / Total Input (%)` hover tooltips — alongside clickable `Total` and `Cost` ascending/descending column sorting.
- **One-Click Session Checkout Receipt (`🧾 结账 / 收工票根`)**: Equivalent Cost's hero row includes a one-click **`🧾 Checkout` / `🧾 结账`** button (`receipt.js` high-DPI `3x` Canvas thermal receipt renderer) to preview and copy a `PNG` **Session Receipt (`收工票根`)** directly to the system clipboard (with automatic local Sidecar `POST /api/copy-receipt` native OS clipboard fallback inside Antigravity's restricted webview iframe), complete with **`Today / All-Time`** (`今日收工 / 全程累计`) scope and **`Compact / Full`** (`精简 / 完整`) detail switches, merged active session duration, date/time span, primary model, subagent & compaction counts, itemized Main + Subagent token/cost rows, and adaptive `EN / ZH` language & `USD / CNY` currency formatting.
- **Prompt Cache & Spike Diagnostics**: Latest cache hit rate (`%`), uncached input, net token delta, and top 5 positive context jumps (`topSpikes`) with triggering tool summaries, complementing the per-model `Hit %` / `命中率` column in both Tab 1 & Tab 2 model tables.
- **Current Session Side Questions Summary & One-Click Open (`支线问题`)**: Automatically discovers linked Antigravity Side Questions for the active conversation from `conversation_summaries.db` (`conversation_parents` + Protobuf `raw_summary` `field 15.17`/`15.18` official titles) and renders an independent **Side Questions (`支线问题`)** summary card at the bottom of Tab 1 (auto-hidden when none exist, sorted by live activity `GENERATING` -> `RUNNING_TOOLS` -> `updatedAtMs` descending). Folds rosters exceeding 5 items to the **Top 5** most recently active with one-click expansion into a `400px` scrollable list (preserving scroll position across live polls), computes strictly fork-deduplicated incremental steps, tokens, cache hit rate, and cost (stripping cloned parent history via `isClonedFromParent` and parent `botId` sets without affecting main-session totals or checkout receipts), provides a one-click **`↗ Open` / `↗ 打开会话`** button on every row to jump straight into that Side Question in Antigravity, and supports in-panel inspection with a **`Side Q` (`支线问题`)** badge, **`Side Question Only` (`支线独立计费`)** cost isolation, and a **`← Back to Main Chat` / `← 返回主对话`** header banner button.
- **Subagent & Swarm Aggregation & Top-5 Recent-Active Folding**: Aggregates token usage and cost across child subagents and swarm workers (`With Subagents` vs `Main Only`) on main conversations while keeping context size isolated; when inspecting an individual subagent or swarm worker directly, Equivalent Cost automatically isolates to that worker's own steps (`Subagent Only`) with no sibling or parent leakage. Sorts child sessions by live activity priority (`GENERATING` -> `RUNNING_TOOLS` -> `updatedAtMs` descending), folds lists exceeding 5 workers to the **Top 5** most recently active by default with one-click expansion into a **`400px` scrollable** container (preserving scroll position across live polls), shows per-worker **relative update time**, active tool labels, and an **`● Ended` (`● 已结束`)** badge for terminated subagents (`manage_subagents` `kill`/`kill_all`) and killed swarm workers, and uses constant-length SHA-256 snapshot ETag digests to prevent `HTTP 431` request header overflows on large subagent/swarm sessions.
- **Daily Official Pricing Sync, Per-Model Rates & Subscription ROI**:
  - Automatically syncs official model lists & Paid Tier pricing once per day on open via dual channels (`ai.google.dev/gemini-api/docs/pricing` with Google Markdoc `<noscript><pre>` SPA extraction + `models.dev/api.json` with `litellm` fallback and effective-date awareness) into `pricing_cache.json` (`CACHE_SCHEMA_VERSION = 2` with non-destructive v1->v2 migration) inside `sidecar_data`, auto-discovers newly released flagship Gemini chat models and locally observed slugs, keeps user-customized `*` overrides highest priority, offers a **`↻ Sync Now` / `↻ 立即同步`** button, and falls back gracefully offline (`8s` timeout).
  - Applies **Scheme A canonical model attribution & merging**: unifies `Orchestrator (Neon)` and SQLite enum IDs `1532`/`1533`/`1535` (`gemini-4-neon`) / `1537` (`gemini-pro-orchestrator-neon`) into first-class **`Gemini 4 Neon`** (`$3.00` / `$0.15` / `$15.00` per 1M tokens) alongside `Gemini 4 Carbon` & `Gemini 4 Argon` (`$2.00` / `$0.10` / `$10.00`, tightened Carbon regex so Neon never collides), and `Gemini 4 Hydrogen` (`$1.50` / `$0.075` / `$7.50`) — all using flat 1M-window pricing (`longContextTier: false`) and 95% cache discounts — plus `Gemini 3.1 Pro` (`$2.00` / `$0.20` / `$12.00`, retaining `>200k` `×2` / `×1.5` tiering), `Gemini 3.8 Flash`, `Claude Opus 5.5`/`4.6`, `Claude Sonnet 5.5`, `GPT-OSS 120B`, and `Auto`. Routes `gemini-flash-worker-agy` via SQLite official `displayModel` first (`Gemini 4 Hydrogen (Orchestrator)` -> `Gemini 4 Hydrogen`, historical `Gemini Flash` -> `Gemini 3.8 Flash`, defaulting worker slugs without an explicit display override to `Gemini 4 Hydrogen`). Displays unified canonical names across the header `#model-pill` and Tab 1 & Tab 2 `byModel` distribution tables (keeping unknown new models in independent rows rather than collapsing into `Auto`), while retaining underlying raw slugs in row hover tooltips (`rawModels`) and Pixel Inspector status lines, with an interactive clickable effective rates table for direct rate editing.
  - Read-only `conversations/<id>.db` + `conversation_summaries.db` Protobuf tracking deduplicates forked/branched/rewound conversations via `originCascadeId` and `botId`, normalizes `gemini-pro-default` to `gemini-3.1-pro` and strips effort-tier suffixes to raw model IDs, compares equivalent API value against recent 14-day model-gated subscription detection (**`Jio AI Pro`** `$0/mo`, `Google AI Pro` `$19.99/mo`, `Ultra 5x`, `Ultra 20x`, plus `Free` / `Custom`), and plots `Cost` / `Tokens` trends across `today`, `7d`, `30d`, and scrollable `all-time` bar charts with two-line KPI summaries and a compact fixed left Y-axis backed by `usage_ledger.json` (`LEDGER_SCHEMA_VERSION = 5`, which automatically rebuilds historical model attribution cleanly on startup).
- **Automatic OS/Environment HTTP(S) Proxy Auto-Detection & High-CPU Anti-Flap Hardening**: Automatically resolves HTTP/HTTPS proxies in priority order (`AGY_TOKEN_MONITOR_PROXY` -> `HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY` -> Windows `HKCU\...\Internet Settings` registry or macOS `scutil --proxy` -> Windows `HKCU\Environment` user env registry fallback, with `%SystemRoot%\System32\reg.exe` fallback on `ENOENT`) and applies them via Node's `http.setGlobalProxyFromEnv` (`4000ms` OS lookup timeout via `DEFAULT_OS_LOOKUP_TIMEOUT_MS`; 5-minute cache on valid snapshots; automatic 15-minute proxy connection pool rebuild; forced pool rebuild & stale `undici` dispatcher close/drain on manual `Sync Now`, `Check Update`, and `Apply Update`). Distinguishes transient OS lookup errors (`ETIMEDOUT`, `EAGAIN`, `ENOMEM`, `ENOBUFS`, `ENOENT`, killed/signal) from absent registry keys so transient probe failures under `100%` CPU load are never cached and never downgrade an already active working proxy to `direct` (rebuilding the active pool instead). On transport/timeout errors (`recoverFromTransportFailure`), detects live OS proxy drift when an inherited `env` proxy goes stale and switches to the live OS proxy (or rebuilds the current pool) without ever bypassing an explicitly configured proxy to `direct`. Unsupported schemes such as `socks5://` are safely ignored without breaking `EnvHttpProxyAgent`, while loopback addresses (`127.0.0.1,localhost,::1`) are guaranteed in `NO_PROXY`.
- **In-Panel 3-Channel Release Check, Plain-Language Update Dialog & SHA-256 CDN Hot Update**: Automatically checks for updates on startup and every 4 hours (cached in `update_cache.json` with ETag `304` support, plus manual check in Settings) across 3 fallback channels: GitHub Releases API (`12s` timeout), GitHub Releases web redirect (`releases/latest`, `8s`), and jsDelivr package metadata (`8s`). Manual checks force a proxy pool rebuild and automatically retry past an in-flight failed background check instead of returning stale failure state, while primary channel or download transport/timeout failures trigger proxy recovery before fallback channels or jsDelivr CDN (`cdn.jsdelivr.net` / `fastly.jsdelivr.net`, `15s` per-file timeout) are tried. Presents plain-language update prompts (`Update Now` / `立即更新`, `Updating…` / `正在更新…`, clear user-friendly failure/rate-limit diagnostics), fixes nested Markdown inline rendering inside `**bold**` spans (`parseCodeAndLinkTokens`, eliminating literal backticks), strips installation, verification/checksum headings, and standalone SHA-256 lines from the localized EN/ZH release notes modal, lets users skip a release tag until the next version, applies one-click SHA-256 verified `.zip` hot updates (`30s` timeout, `45 × 3.5s` sidecar restart wait) — or falls back to jsDelivr CDN with per-file Base64 SHA-256 verification against `@ref/flat` while preserving all integrity/manifest/downgrade guards — keeps local preferences (`monitor_state.json`) and usage history (`usage_ledger.json`) intact, and surfaces colored warning/error toasts alongside Settings tooltip proxy diagnostics (`Proxy: <url> (<source>)` / `Direct connection`).

## How to Surface the Panel Link

1. **Check plugin state if uncertain** (read-only):
   - Query `GetAllPlugins` filtered to `{ name, dir, disabled, isGlobal }` (never print unfiltered `GetAllPlugins` output, never edit `~/.gemini/config/config.json`, and never call mutation RPCs).
2. **When `agy-token-monitor` is enabled and running**:
   - Surface the clickable Aux Pane pill on its own clear line so the user can open/toggle the side panel in one click:

     [Token Monitor](sidecar://agy-token-monitor/monitor_pane/)

   - Emit only one `sidecar://` pill per view and avoid repeating it if already opened in the current flow.
3. **When `agy-token-monitor` is disabled (or not yet enabled by the user)**:
   - Do **not** emit a `sidecar://` pill for a disabled plugin. Instead, surface the Customizations page link so the user can enable it (takes effect live with no restart):

     [Token Monitor](customization://agy-token-monitor)

   - Never emit `plugin://` or `plugins://` links.

## Standalone Local Debugging (Only If Requested)

If the user explicitly asks to preview or debug the dashboard outside Antigravity's Aux Pane, point them to:

```bash
node sidecars/monitor_pane/main.mjs --standalone 18923
```

Then open `http://127.0.0.1:18923/` in a browser.
